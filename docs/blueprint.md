# **App Name**: OncoAssist

## Core Features:

- Symptom Tracker: Symptom and Side Effect Tracking with intensity ratings and detailed descriptions, visualized over time.
- Reminder System: Medication and Appointment Reminders with push notifications for improved adherence.
- Secure Messaging: Secure Direct Provider Messaging with one-to-one chat functionality and clear delineation between patient and provider accounts.
- Educational Content: Curated library of general articles/FAQs on common cancer-related topics and a medical glossary. AI will tool be used to simplify language based on readability scores for target audience.
- Mood Journal: Mood Tracking & Journaling using emojis and free-text to record thoughts and feelings, timestamped and private.

## Style Guidelines:

- Primary color: Soft Lavender (#D1C4E9) to evoke a sense of calm and healing.
- Background color: Light Gray (#F5F5F5) for a clean, uncluttered interface.
- Accent color: Pale Violet (#E1BEE7) to highlight key interactive elements and CTAs.
- Body text: 'PT Sans' (sans-serif) for clear, accessible information.
- Headline font: 'Alegreya' (serif) with a clean and modern feel, contrasting gently with body
- Simple, easily recognizable icons to represent different symptoms, moods, and actions. Minimize the use of disease-specific imagery which might have negative associations.
- Use clear and intuitive navigation with a tab-based or bottom navigation bar for core features. Ample white space and a card-based layout for information density and easy scanning.
- Subtle animations for transitions and feedback, such as a gentle fade-in or slide-up effect, to enhance usability without overwhelming users.
